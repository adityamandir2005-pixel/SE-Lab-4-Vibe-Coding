# SE Lab-4 VIbe Coding — Fruit Catcher

A small Pygame arcade game about catching fruit and dodging hazards.

## Run

Requirements: Python 3.10 or newer.

1. Install dependencies: python -m pip install -r requirements.txt
2. Start the game: python main.py

## Controls

- Move the basket with A / D or the Left / Right arrow keys.
- Press R on the Game Over screen to restart.
- Close the game window to exit.

## Features

- Catch apples, oranges, and grapes for points.
- Missed regular fruit and caught bombs cost a life; rotten fruit reduces score.
- Falling speed and spawn rate increase with the score.
- Splash particles appear when items are caught or hit the floor.
- The game starts with three lives and supports restarting after Game Over.
